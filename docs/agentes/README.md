# Documentos producidos por el equipo de agentes (repositorio anterior)

Estos tres documentos los redactaron los agentes del proyecto «Desarrollo del Portal» mientras el repositorio registrado
era una carpeta distinta a la del propio Portal (por eso su código no llegó nunca a esta base). Las reglas que proponen
—`main` como única fuente de verdad, una rama por historia desde `main`, integrar y publicar con autorización, aviso de
recarga/reinicio, comprobación de la carpeta desde la que corre el Portal— están implementadas en esta versión (v0.8).
Se conservan como conocimiento del proyecto.
